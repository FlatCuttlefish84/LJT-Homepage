# LJT-Homepage

Personal academic homepage for **Junteng Liu**, first-year Ph.D. candidate in the [HKUST NLP Group](https://github.com/hkust-nlp) at the Hong Kong University of Science and Technology (HKUST).

> The external link above points to the group's public GitHub organization; all personal and academic content on this site comes from the owner's recorded profile.

This site is built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template. It contains two content sections:

- **About** (`_pages/about.md`): personal details, academic background, research experience, publications, skills/research interests, and contact information.
- **Publications** (`_pages/publications.html` and `_publications/`): the publication list.
